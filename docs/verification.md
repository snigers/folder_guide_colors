# Проверка Folder Guide Colors 0.1.0

Дата: 2026-11-11. Исходная рабочая папка была пуста, кроме служебных каталогов среды. Рабочего Git-репозитория не было; существующие проектные файлы не изменялись. Созданы исходники, тесты, документация, лицензии и VSIX. Commit, push, публикация в Marketplace и установка в основной профиль пользователя не выполнялись.

## Автоматические проверки

- `npm test`: **17/17 PASS**. Временные файлы и настоящие локальные HTTP/WebSocket-серверы; DOM-проверки на JSDOM.
- `npm run check`: **PASS**, синтаксис всех исходников, тестов и скриптов.
- `node scripts/check-browser.js`: **PASS** в установленном Google Chrome. Проверены вычисленные CSS-цвета на 40 уровнях, повторение палитры, активная линия, отсутствие окраски другого дерева, повторное внедрение и отключение.
- `npm run package`: **PASS**, VSIX включает runtime-зависимости `ws` и `jsonc-parser`, их лицензии и MIT-лицензии заимствованных частей. В пакете нет dev-зависимостей, тестовых профилей или нативных модулей.

Тесты проверяют сохранность существующего порта и посторонних JSONC-параметров/комментариев; удаление только собственного порта; пользовательскую замену порта; повторное включение; некорректную конфигурацию; откат ошибки записи; символьные ссылки и права доступа; Windows-пути; фильтрацию CDP-целей и адресов; ошибки/таймауты/закрытие/повреждённые сообщения; восстановление после reload и отключение несколькими контроллерами, в том числе после временного сбоя discovery.

## Настоящий VS Code из Snap

Версия **1.145.2**, установка `/snap/code/278`. Выполнен `node scripts/check-snap.js` с собранным VSIX. Созданы отдельные временные portable-каталоги пользовательских данных и расширений; основной профиль не использовался.

Итог успешного прогона:


Первое тестовое окно получило временный CLI-порт для автоматизации. Команда самого расширения записала собственный порт в тестовую runtime-конфигурацию. После полного выхода приложение запускалось **без CLI-порта**, что проверило сохранение параметра запуска и автоматическую активацию. Измерены реальные цвета штатных направляющих, а не только наличие style-элемента.

В чистом профиле Agents автоматически показывает предложение входа в GitHub. Для проверки цветов события раскрытия отправлялись штатным элементам дерева через DOM, без входа в аккаунт и без отправки сообщений агентам. Для проверки команды отключения экран входа закрывался штатным действием Continue Without Signing In. Это автоматизированное runtime-испытание, а не пользовательская приёмка в рабочем профиле.

До успешного прогона тестовый сценарий уточнялся: префикс палитры команд, локальные модальные диалоги, фокус отдельных окон и приветственный экран Agents. Эти сбои автоматизации не выдавались за успешную проверку продукта. Успешный профиль удаляется, тестовые процессы закрываются.

## Независимое ревью

Отдельный агент выполнил чтение кода и повторное ревью. Два существенных замечания воспроизведены падающими тестами и исправлены:

1. Библиотечное удаление свойства JSONC могло удалить соседние комментарии. Теперь удаляются только синтаксические токены свойства и запятая.
2. Временная ошибка discovery во время Disable могла навсегда завершить очистку преждевременно. Теперь отключение повторяет попытку после восстановления endpoint.

Повторное ревью: **нет оставшихся Critical/Important замечаний**. Проверены тесты, синтаксис и содержимое VSIX.

## Границы результата

- **Windows runtime: NOT_TESTED**. Подготовлены единый пакет без нативных модулей и обработка Windows-путей; одних этих проверок недостаточно для утверждения, что выполнен запуск на Windows.
- Проверка Snap использовала отдельный portable-профиль. Основной пользовательский профиль и его установленные расширения не менялись и не проходили пользовательскую приёмку.
- Цвета зависят от внутреннего DOM VS Code. Другие версии и будущие обновления требуют проверки. Используется CDP, а не поддерживаемый API настройки направляющих.
- Runtime-проверка охватила три вложенные папки; цикл до 40 уровней проверялся в Chromium. Сжатые папки и multi-root следуют отображаемой структуре штатного дерева, но не проходили отдельную ручную приёмку.
