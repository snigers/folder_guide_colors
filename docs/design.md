# Цветные направляющие дерева файлов

Согласованная основа: разбор в чате и разрешение пользователя от 2026-11-11 начать создание плагина.

Нужно автоматически различать уровни раскрытых папок по цветам вертикальных линий в штатном Explorer VS Code и Agents. Названия, иконки, фон и другие деревья не окрашиваются. Шесть цветов повторяются при любой глубине; компактные папки используют отображаемую глубину дерева. Linux со Snap и Windows используют один VSIX.

Официальный API не позволяет менять CSS Explorer. Изменение установки исключено из-за Snap. Собственный файловый проводник не удовлетворяет задаче. Выбран небольшой локальный UI extension: подключение к renderer через CDP и отдельный элемент style. Это неподдерживаемая настройка внутренних стилей VS Code; после обновлений нужны проверки.

При Enable расширение сохраняет строковый remote-debugging-port в пользовательской конфигурации запуска, если он ещё не настроен, и собственное состояние рядом с ней. При необходимости пользователь полностью перезапускает приложение. Порт доступен локально и позволяет управление интерфейсом другим локальным процессам; команда предварительно объясняет это условие. Не меняются файлы установки, системные ярлыки, настройки проектов или параметры sandbox.

После запуска расширение восстанавливает стили в подходящих окнах и следит за перезагрузкой. При Disable удаляет свои стили и только добавленный им параметр порта, если пользователь не изменил его. Чужие параметры и комментарии сохраняются. Закрытие отладочного порта требует полного выхода из VS Code. Удаление расширения не вызывает надёжный uninstall hook: сначала Disable.

JavaScript CommonJS, ws, jsonc-parser. Зависимости без нативных модулей. Переиспользованы CSS-подход Colorize Folder Tree и DOM/CDP-подход slack-themes; точные версии и MIT-лицензии поставляются с расширением.

Проверки: JSONC и сохранность чужих изменений, ограничение CDP-целей, ошибки и таймауты протокола, смена окон/перезапуск, идемпотентное добавление и удаление стилей, реальные вычисленные цвета в Chromium. Отдельно фиксируются испытания установленной Snap-версии и отсутствие проверки Windows, если Windows недоступна.
