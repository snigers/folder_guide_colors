# Folder Guide Colors Implementation Plan

**Goal:** Автоматические цветные линии штатного дерева файлов на Linux/Snap и Windows.

**Architecture:** Локальное UI-расширение с двумя командами, пользовательская конфигурация запуска, CDP и ограниченный CSS. Файлы установки не изменяются.

**Tech Stack:** JavaScript, Node.js, ws, jsonc-parser, node:test, Chromium.

**Spec:** [design.md](../../design.md)

## Global Constraints

- Только линии Explorer; обычный VS Code и Agents.
- Один VSIX без нативных зависимостей; Linux/Snap и Windows.
- Не изменять установку или параметры sandbox; сохранять пользовательские JSONC-настройки.
- Пользователь разрешил создание и адаптацию; выполняем в текущей папке без commit/push.

## Review Focus

- Отключение при другом запущенном окне не должно возвращать стили.
- Ошибочный или чужой CDP endpoint не должен получать выполнение JavaScript.
- Пользовательская правка порта и комментариев должна пережить Disable.
- Перезагрузка renderer и запуск только Agents должны восстанавливать стили.
- Ожидающие запросы и таймеры должны завершаться при отключении.
